# Database Documentation

## Кестелер тізімі
1. `specializations` — дәрігер мамандықтары
2. `departments` — клиника бөлімшелері
3. `doctors` — дәрігерлер тізімі
4. `patients` — пациенттер деректері
5. `insurance_companies` — сақтандыру компаниялары
6. `patient_insurance` — пациенттердің сақтандыру полистері
7. `services` — медициналық қызметтер мен бағалары
8. `appointments` — дәрігерге жазылу және қабылдаулар
9. `appointment_services` — қабылдауда көрсетілген қызметтер
10. `medical_records` — медициналық карта жазбалары
11. `diagnoses` — диагноздар (МКБ кодтарымен)
12. `medicines` — дәрілік препараттар
13. `prescriptions` — тағайындалған рецепттер
14. `laboratory_tests` — зертханалық талдау түрлері
15. `test_results` — талдау нәтижелері
16. `payments` — төлемдер және сақтандыру өтемақылары
