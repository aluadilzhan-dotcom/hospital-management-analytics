# Project Brief: Hospital Management System (Case 03)

## Мақсаты
Көпбейінді жеке медициналық орталықтың пациенттерін тіркеу, дәрігерлер кестесін, медициналық карталарды, зертханалық талдауларды, сақтандыру полистерін және қаржылық есеп айырысуларды басқаруға арналған реляциялық деректер базасын жобалау.

## Міндеттер
1. Нормаланған 16 кестеден тұратын деректер базасын құру.
2. Деректер тұтастығын `PRIMARY KEY`, `FOREIGN KEY`, `UNIQUE`, `CHECK` шектеулері арқылы қамтамасыз ету.
3. Бизнес-операциялар мен 4 негізгі аналитикалық есепті SQL сұраныстар арқылы іске асыру.
