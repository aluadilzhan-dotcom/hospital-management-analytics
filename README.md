# Hospital Management System (Медициналық орталық)

Көпбейінді жеке медициналық клиниканың деректер базасы және аналитикалық жүйесі (PostgreSQL / pgAdmin 4).

## Жоба құрылымы
- `database/` — кестелерді құру (`01_create_tables.sql`), тест деректерін енгізу (`02_insert_data.sql`) және шектеулер (`03_constraints.sql`).
- `queries/` — базалық сұраныстар, сүзгілеу, агрегация, JOIN, бизнес-функциялар және аналитикалық есептер.
- `docs/` — жоба сипаттамасы, кестелер құжаттамасы, ERD схемасы және қорытынды есеп.
- `results/` — аналитикалық сұраныс нәтижелері мен қорытынды талдау.
- `presentation/` — жоба презентациясы (`final_presentation.pdf`).

## Негізгі функциялар мен есептер
- Пациентті тіркеу және дәрігерге жазылу
- Қызмет құнын сақтандыру полисін ескере отырып есептеу
- Зертханалық талдау нәтижелерін енгізу
- Ең көп қабылдау жасайтын дәрігерлер, сұранысқа ие қызметтер, бөлімшелер бойынша табыс және төленбеген емдеу есептері
